# 2026-05-02 — Phase 3 PWA (manifest + SW + push UI)

## Objetivo

Transformar o frontend Next.js em PWA: instalável, offline-first, com push notifications conectadas ao backend VAPID já existente.

## O que foi feito (5 commits, prefixo `feat(pwa):`)

- **`cb01ae3`** — Manifest + ícones SVG maskable (192/512), theme #0f172a
- **`71adc84`** — `public/sw.js`: network-first /api, cache-first static, push listener, notificationclick → openWindow(data.url)
- **`39ca00d`** — `<ServiceWorkerRegistrar>` no layout + viewport themeColor
- **`72c8d19`** — `<EnablePush>` (VAPID subscribe com `urlBase64ToUint8Array`) + `<InstallPrompt>` (beforeinstallprompt) no dashboard
- **`1e49d0d`** — Docs (apps/web/README + TODO + README raiz)

## Decisões

- **`sw.js` em JS plano** (não TS): Next.js App Router não compila TS dentro de `public/`. Service worker é servido raw.
- **Cache version `scanner-v1`**: bump manual quando estratégias mudam força clientes a invalidar.
- **Ícones SVG maskable**: cobre Chrome/Edge/Safari modernos. iOS antigo prefere PNG raster — está no backlog.
- **EnablePush no rodapé do dashboard**: descoberta orgânica em vez de modal intrusivo no primeiro load.
